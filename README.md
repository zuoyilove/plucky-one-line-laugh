One funny line for the "One Line, One Laugh" bounty: the standing desk that lost to a taller chair.

## Run it

```sh
node main.ts
```

The program prints the line to stdout and writes it to `/output/entry.txt` (73 characters, UTF-8). Locally, `MAKEFUN_OUTPUT_DIR` points the write at another directory instead.
